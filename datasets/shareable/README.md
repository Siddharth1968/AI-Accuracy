# Approved Shareable Datasets (`datasets/shareable/`)

This folder is reserved exclusively for datasets whose **public redistribution rights have been explicitly verified**.

Currently, **no locally discovered facial-expression datasets have been placed in this folder**:
- **JAFFE** explicitly prohibits redistribution (including GitHub/Kaggle).
- **ExpW** is restricted to non-commercial academic/educational research without a public redistribution grant.
- **FER2013** originates from web-scraped face photographs without verified individual model releases.
- **CREMA-D** (`LICENSE.txt`: ODbL 1.0 / DbCL 1.0) is kept in `datasets/local_library/` pending explicit ODbL attribution/share-alike and human-subject redistribution review.

All locally available datasets are stored strictly inside `datasets/local_library/` (excluded from Git via `.gitignore`).
